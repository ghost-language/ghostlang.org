The `math` module provides a set of mathematical functions and constants.

<callout>[Lumen](/docs/lumen) adds a good deal more to this same module — `floor`, `ceil`, `sqrt`, `clamp`, `lerp`, and others. See [Math (Lumen)](/docs/game-math).</callout>

### `abs()`

Returns the absolute, or non-negative value, of a given value.

```typescript
math.abs(-100)

// expected value: 100
```

### `cos()`

Returns the cosine of the radian argument.

```typescript
math.cos(math.pi / 2).round()

// expected value: 0
```

### `isNegative()`

Determines if the specified value is negative.

```typescript
math.isNegative(-100)

// expected value: true
```

### `isPositive()`

Determines if the specified value is positive.

```typescript
math.isPositive(100)

// expected value: true
```

### `isZero()`

Determines if the specified value is zero.

```typescript
math.isZero(5)

// expected value: false
```

### `max()`

Returns the larger of two numbers. Extra arguments beyond the first two are ignored.

```typescript
math.max(100, 200)

// expected value: 200
```

### `min()`

Returns the smaller of two numbers. Extra arguments beyond the first two are ignored.

```typescript
math.min(100, 200)

// expected value: 100
```

### `sin()`

Returns the sine of the radian argument.

```typescript
math.sin(math.pi).round()

// expected value: 0
```

### `tan()`

Returns the tangent of the radian argument.

```typescript
math.tan(0).round()

// expected value: 0
```

### `e`
The mathematical constant `e = 2.718281…`, use the `round()` method to round down to the desired precision.

```typescript
math.e.round(2)

// expected value: 2.72
```

### `epsilon`
The smallest positive value a decimal can hold that is still distinguishable from zero (`5e-324`).

```typescript
math.epsilon

// the smallest positive decimal, 5e-324
// (printing it writes the value out in full)
```

<callout>This is the smallest representable decimal, not the machine epsilon (`2.22e-16`) that some languages give this name to. For "are these two decimals close enough", pick a tolerance that suits your numbers rather than using this.</callout>

### `pi`
The mathematical constant `π = 3.141592…`, use the `round()` method to round down to the desired precision.

```typescript
math.pi.round(2)

// expected value: 3.14
```
