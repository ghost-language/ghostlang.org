The `io` module reads and writes files. Every path is joined onto the directory of the running script, so paths are relative to your program rather than to whatever directory it happens to be run from. A leading `/` is folded into that join rather than being treated as an absolute path.

## Methods

### `io.append()`
Appends content to the specified file, creating the file if it does not exist. Takes the path first and the content second.

```typescript
io.append('./log.txt', 'message from ghost')
```

### `io.read()`
Reads and returns the contents of the specified file as a string. A file that cannot be read raises a runtime error.

```typescript
contents = io.read('./log.txt')
```

### `io.write()`
Writes content to the specified file, replacing everything already in it. Takes the path first and the content second.

```typescript
io.write('./log.txt', content)
```

<callout>`io.write()` only writes to a file that already exists — it keeps the file's existing permissions rather than inventing new ones, so it needs the file to be there to read them from. Use `io.append()` to create a file.</callout>
